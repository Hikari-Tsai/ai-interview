# Community answers

Add reviewed, human-authored answers at `Qxxxx/en.md`, `Qxxxx/zh-TW.md`, or `Qxxxx/ja.md`.

Use the **Edit the answer** link on a question card to get a starter with its current source fingerprint and original repository links. Complete the metadata and four required sections, then submit a pull request.

These files take priority over generated answers in the matching language and are never overwritten by the scheduled generator. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the format, attribution, source review, and publishing workflow.
