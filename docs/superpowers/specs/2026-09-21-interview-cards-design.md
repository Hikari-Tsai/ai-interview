# AI Interview Cards — approved design
A static trilingual interview practice app sourced from pallavi-shekhar/ai-engineering-interview-questions-company-wise.

## Requirements
One question per /{locale}/questions/{id}/ route. Locales zh-TW, en, ja; zh-TW default. All interface copy and tag labels in lang/*.json. Stable numeric question IDs; sequential mode ascending by number. Random mode shuffles without repetition within selected filters; retains current card on mode changes; previous returns actual prior card. Filter tags any/all plus optional search and company. URL retains filters, mode and shuffle seed across locale changes and refresh. Filter changes retain current question when eligible. Hint and answer independently collapsed on each new card. Four answer sections: principle, tradeoff, implementation, production. Preserve original English question, original README answer, ALL original answer links; every answer has immutable original-repo permalink and repo home. Missing/stale translations clearly labelled; no invented sourced answers.

## Data and updates
Question and Answer contracts in src/lib/types.ts. Questions per data/questions/Q0001.json; answers per data/answers/Q0001.json. Metadata under data/sources and data/state. Editorial overrides under data/overrides. Source prose exclusively .private (gitignored) with optional encrypted persistent CI cache. Read README at pinned commit; compare blob SHA before download. Parse full changed README via AST; preserve IDs by exact normalized text, conservative move matching; unknown edits treated as new+retired rather than silent fuzzy association. Detect abnormal shrink before changing persisted state. External sources conditional-fetch weekly; normalized article body hashes invalidate dependent answers. Daily processing retries pending work even with unchanged README. No API credentials in client. Model generation schema validated, bounded, resumable and provenance checked. One job builds and deploys explicit artifact after data changes. No external deployment without configured repository.
